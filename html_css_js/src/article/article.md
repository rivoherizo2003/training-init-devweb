# TP : Mise en page d’un article

## Objectif

Dans ce TP, vous allez réaliser une page d’article avec HTML et CSS en mettant en œuvre les notions de mise en page, d’images flottantes, de typographie et de structure de contenu.

## Contexte

Un article de blog ou de site d’actualité doit être lisible, agréable à parcourir et visuellement équilibré. L’objectif est de créer une page dont le texte est bien organisé, avec des éléments visuels qui renforcent la lecture sans la gêner.

## Consignes

1. Créez une page HTML dans ce dossier.
2. Structurez le contenu en deux paragraphes.
3. Intégrez du texte dans chaque paragraphe.
4. Placez chaque image dans chaque texte.
5. Stylisez la page avec un fichier CSS séparé.
6. Utilisez des propriétés CSS pour gérer :
   - la largeur du conteneur,
   - les marges et paddings,
   - la couleur du texte,
   - la taille des titres,
   - l’alignement du texte,
   - la mise en page de l’image et du texte.
7. Faites en sorte que la page soit lisible et visuellement harmonieuse.

## Exigences du rendu

Votre page doit comporter :

- plusieurs paragraphes de contenu
- une image intégrée dans le texte
- un style visuel cohérent
- un bon contraste entre les éléments

Rendu: article.png

## Critères de réussite

- La page est bien structurée
- Le texte est facile à lire
- L’image est correctement positionnée
- La mise en page est propre et équilibrée
- Le code HTML et CSS est clair et bien organisé

## À rendre

- un fichier HTML
- un fichier CSS
- une page d’article complète et fonctionnelle

## Durée estimée

20 à 30 minutes
