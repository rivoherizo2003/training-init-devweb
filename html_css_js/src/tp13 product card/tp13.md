# TP 13 : Product Card / Carte produit

## Objectif

Dans ce TP, vous allez concevoir une carte produit moderne en HTML et CSS. L’objectif est de maîtriser la mise en page, les dimensions, les couleurs, les ombres, les bordures et le style visuel d’un élément de commerce électronique.

## Contexte

Les cartes produits sont très utilisées dans les sites e-commerce. Elles permettent de présenter un article de manière attractive et lisible, avec une image, un titre, un prix, une description et éventuellement un bouton d’action.

## Consignes

1. Créez une page HTML nommée `index.html` dans ce dossier.
2. Concevez une carte produit contenant :
   - une image du produit
   - un nom du produit
   - une courte description
   - un prix
   - un bouton d’achat ou d’ajout au panier
3. Stylisez la carte avec des propriétés CSS telles que :
   - `display`, `flex` ou `grid`
   - `width`, `height`, `padding`, `margin`
   - `border-radius`, `box-shadow`, `border`
   - `background-color`, `color`
   - `transition` pour les effets au survol
4. Ajoutez un effet visuel au survol :
   - changement de couleur
   - légère translation
   - ombre plus marquée
   - zoom sur l’image
5. Utilisez des couleurs harmonieuses et un design cohérent.
6. Vérifiez le rendu dans le navigateur et ajustez les espacements si nécessaire.

## Structure attendue

Votre projet peut avoir une structure de type :

```text
tp13 product card/
├── index.html
├── css/
│   └── style.css
├── images/
│   └── produit.jpg
├── tp13.md
```

## Exercice pratique

Créez une carte produit qui présente :

- un produit de votre choix (chaussure, sac, montre, smartphone, etc.)
- une image du produit
- un titre clair et attractif
- une description courte et élégante
- un prix affiché en évidence
- un bouton "Acheter" ou "Ajouter au panier"

## Critères de réussite

- La carte est bien structurée et visuellement agréable
- Les effets de survol sont fonctionnels
- Le design est moderne et lisible
- Le code HTML et CSS est propre et bien organisé
- La page s’affiche correctement dans le navigateur

## Conseils

- Utilisez des images en ligne ou dans le dossier `images/`.
- Testez les dimensions pour éviter un rendu trop étiré ou trop serré.
- Faites attention au contraste entre le texte et le fond.
- Gardez la mise en page simple mais élégante.

## À rendre

- un fichier `index.html`
- un fichier CSS de style
- éventuellement les images utilisées

## Durée estimée

30 à 45 minutes

## Évaluation

L’évaluation portera sur :
- la qualité du design visuel
- la structure HTML/CSS
- l’utilisation des effets de survol
- la lisibilité et la cohérence globale de la carte produit
