# TP 12 : Polices et typographie

## Objectif

Dans ce TP, vous allez apprendre à intégrer et utiliser des polices personnalisées dans une page web avec HTML et CSS, en maîtrisant les notions de typographie, de chargement de fichiers de police et d’application de styles de texte.

## Contexte

Les navigateurs disposent de polices de base, mais elles sont souvent limitées. Il est possible d’utiliser des polices externes pour améliorer le rendu visuel d’une page web. Dans ce TP, vous allez importer des fichiers de police, les utiliser dans votre interface et ajuster la mise en page.

## Consignes

1. Créez une page HTML nommée `index.html` dans ce dossier.
2. Ajoutez un titre principal, des sous-titres et un paragraphe de texte.
3. Utilisez au moins une police personnalisée depuis un fichier local ou un service de polices (ex. Google Fonts, ou un fichier `.woff` / `.woff2` dans le dossier `fonts/`).
4. Appliquez des styles CSS dans un fichier séparé `css/style.css` (ou autre nom).
5. Expérimentez avec les propriétés CSS suivantes :
   - `font-family`
   - `font-size`
   - `font-weight`
   - `font-style`
   - `line-height`
   - `letter-spacing`
6. Ajoutez un bloc de texte mis en avant avec une couleur, une taille différente et une police spécifique.
7. Mettez en place un design simple et lisible, avec un fond clair et un bon contraste.
8. Vérifiez le rendu dans le navigateur et ajustez les tailles et espacements si nécessaire.

## Structure attendue

Votre projet peut avoir une structure de type :

```text
tp12 fonts/
├── index.html
├── css/
│   └── style.css
├── fonts/
│   └── (fichiers de police si nécessaire)
```

## Exercice pratique

Créez une page qui présente :

- un titre principal : "Bienvenue dans le monde des polices"
- un sous-titre : "Typographie et design web"
- trois paragraphes de texte sur l’importance de la typographie dans une interface web
- un bouton ou un encadré visuel qui utilise une police différente pour attirer l’attention

## Critères de réussite

- La page est bien structurée
- Les polices sont correctement chargées et visibles
- Le design est agréable et lisible
- Les styles CSS sont bien organisés
- La page fonctionne sans erreur dans le navigateur

## Conseils

- Vérifiez que les chemins d’accès aux fichiers CSS et aux polices sont corrects.
- Si vous utilisez des fichiers de police locaux, placez-les dans le dossier `fonts/` et utilisez `@font-face`.
- Faites attention à la compatibilité des formats (`.ttf`, `.otf`, `.woff`, `.woff2`).

## À rendre

- un fichier `index.html`
- un fichier CSS de style
- éventuellement les fichiers de police utilisés
