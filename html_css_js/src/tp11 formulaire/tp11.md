# TP11 - Créer un Formulaire de Facture

## Objectif

Créer un formulaire HTML complet et stylisé pour la gestion de factures, en maîtrisant les éléments de formulaire et leur mise en page CSS.

## Compétences ciblées

- Structurer un formulaire HTML avec `<form>`, `<fieldset>` et `<legend>`
- Utiliser différents types d'inputs : `text`, `date`, `email`, `number`, `radio`, `checkbox`
- Intégrer un `<textarea>` et un `<select>`
- Mettre en forme un formulaire avec CSS
- Créer une table HTML pour afficher les détails des produits
- Organiser la mise en page avec des conteneurs et des groupes de champs
- Javascript

---

## Consignes

### Partie 1 : Structure HTML

#### 1.1 - Formulaire "Création d'une nouvelle facture"

- Créez un document HTML5 valide avec `<!DOCTYPE html>`
- Ajoutez un titre de page : **Nouvelle Facture**
- Créez un conteneur principal avec la classe `invoice-container`
- Créer un formulaire avec les différentes sections suivantes:

##### 1.1.1 - Section "Informations Générales"

Créez un premier `<fieldset>` avec la légende **"Informations Générales"** contenant :

- **Numéro de facture** : input `type="text"` avec placeholder "ex: FACT2025-001", attribut `required`
- **Date de la facture** : input `type="date"`, attribut `required`
- **Commentaire** : textarea avec 4 lignes, placeholder "Ajoutez une note ou des conditions de paiement..."

Chaque champ doit être enveloppé dans une `<div class="form-group">` avec un `<label>` associé.

##### 1.1.2 - Section "Options de Facturation"

Créez un deuxième `<fieldset>` avec la légende **"Options de Facturation"** contenant :

- **Inclure la TVA (20%)** : deux `<input type="radio"` (Oui/Non) groupés dans une `<div class="radio-group">`
  - Oui sélectionné par défaut
  - Les deux options doivent partager le même attribut `name`
- **Email du client** : input `type="email"`, placeholder "<exemple@client.com>", `required`
- **Montant payé (€)** : input `type="number"` avec `min="0"`, `step="0.01"`, placeholder "0.00"
- **Méthode de paiement** : dropdown `<select>` avec options :
  - Carte de crédit
  - Virement bancaire
  - PayPal
  - Espèces

##### 1.1.3 - Section "Actions Finales"

Créez un troisième `<fieldset>` avec la légende **"Actions Finales"** contenant :

- Un `<input type="checkbox"` : "Imprimer la facture après enregistrement"

#### 1.2 - Section "Ajouter un produit"

Créez un quatrième `<fieldset>` avec la légende **"Ajouter un produit"** contenant :

- Un formulaire avec les champs suivantes:
  - Nom produit (texte)
  - Quantité (chiffre)
  - P.U (chiffre)
  - Un bouton submit "Ajouter"

#### 1.6 - Tableau des produits

Après le formulaire, créez une table avec :

- **En-tête** : Description du Produit | Quantité | Prix Unitaire (€) | Total (€)
- **Corps** : vide
- **Pied de table** : Ligne "Total Général" avec le montant 1250.00

1. **Ajouter des boutons** : Créez un div `form-actions` avec des boutons type button "Enregistrer la facture" et "Réinitialiser"

2. **Responsive** : Adaptez le formulaire pour les écrans mobiles avec des media queries

## Résultat attendu

Un formulaire professionnel et bien organisé avec :

✓ Trois sections distinctes avec `<fieldset>`

✓ Tous les types d'inputs utilisés correctement

✓ Une mise en forme cohérente et lisible

✓ Une table bien présentée avec les détails des produits

✓ Une expérience utilisateur fluide avec des effets au focus

✓ Créer une variable global bill dans votre fichier javascript:

```javascript
  let bill = {
  data: null,
  productDetails: [],
};
```

### Section "Ajouter produit"

A chaque fois qu'on clique sur le bouton submit "Ajouter":

✓ Une ligne tr, sera crée dans la table;

✓ La colonne total sera calculer(quantite * PU) pour chaque ligne et afficher pour chaque ligne;

✓ Total général sera calculer (Somme total de chaque ligne) pour tout les produits dans la table et afficher dans la partie "Total Général"

✓ Ajouter le contenu de ce formulaire dans la clé productDetails qui est un tableau. Ce tableau aura donc deux produits comme élément si vous cliquez deux fois sur le bouton ajouter;

```javascript
let bill = {
    "data": null,
    "productDetails": [
        {
            "product_name": "stylos",
            "product_quantity": "3",
            "product_unit_price": "1000"
        },
        {
            "product_name": "crayon",
            "product_quantity": "3",
            "product_unit_price": "2300"
        }
    ]
}
```

### "Enregistrer la facture"

Quand on clique sur le bouton(type button) "Enregistrer la facture":

  ✓ Déclencher via javascript le submit du formulaire(ce formulaire n'a pas de bouton submit);
  
  ✓ Ajouter un event submit au formulaire "Nouvelle facture" et récupérer tous les données dans le formulaire via javascript;

  ✓ Stocker les données du formulaire "Nouvelle facture" dans le key "data" de la variable bill c'est à dire les informations: numéro facture jusqu'à la checkbox "Imprimer la facture après enregistrement" ;

  ✓ Créer le fichier json bill.json avec tout le contenu des formulaires "Nouvelle facture" et les détails factures (toutes les produits ajoutés);

  ✓ Télécharger le fichier;

  Exemple de fichier bill.json:

  ```json
  {"data":{"invoice_num":"FAC0098","invoice_date":"2026-12-12","comments":"Comment","tva_option":"yes","client_email":"exemple@client.com","amount_paid":"30000","payment_method":"transfer"},"productDetails":[{"product_name":"stylos","product_quantity":"3","product_unit_price":"1000"},{"product_name":"stylos","product_quantity":"3","product_unit_price":"1000"}]}
  ```
