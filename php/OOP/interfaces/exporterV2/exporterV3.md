# Exercice POO PHP : Système de Notification Multi-Canal (Interfaces & SOLID)

## Objectif

- Se connecter à une base de données et d'y insérer les données saisie dans le formulaire quand l'utilisateur clique sur le bouton exporter.
- Lister les lignes insérés dans la table de la base de données en dessous du formulaire.

## Contexte

Le formufaire:

- Nom du fichier (input:text)
- Contenu (Textarea)
- Choix:
  - pdf
  - csv
  - txt
- Un bouton submit pour Exporter

- Un tableau listant les exports enregistrés dans la base de données

***Note*** :

- Il faut une jolie interface svp pour le formulaire et pour le tableau (html)
