# Utilisation fetch pour accéder à des données en base

## Appel fetch

- Insérer les données dans une formulaire d'ajout dans une table en base de données via fetch.
- Utiliser fetch pour sauvegarder les données dans une formulaire d'édition. (Update des informations en base quand l'utilisateur valide le formulaire)
- Supprimer une ligne dans une liste via un bouton ou lien "Delete". La ligne sera supprimer dans la table et supprimer dans la liste sur l'interface.

Bonus: Ajouter une modal de confirmation sur le bouton de suppression "Delete"
