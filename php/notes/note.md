# Énoncé 1

Créez un tableau $etudiants contenant plusieurs étudiants. Chaque étudiant est un tableau associatif avec un nom et une liste de notes (un tableau d'entiers).

Créez une fonction calculerMoyenne(array $notes): float qui retourne la moyenne d'un tableau de notes.

Créez une fonction genererAppreciation(float $moyenne): string qui retourne :

    - "Excellent" si moyenne≥16

    - "Bien" si moyenne≥12

    - "Passable" si moyenne≥10

    - "Insuffisant" sinon.

Affichez les résultats dans une page HTML propre (utilisez une liste ou un tableau)
